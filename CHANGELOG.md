# Changelog

Notable project milestones and changes. Dates are based on the repository's commit history. This is a curated summary, not a list of every commit.

## Unreleased

- Renamed the existing Synth voice to Mono Synth and added an FM Synth voice.
- Corrected voice type capitalization and ensured FM Synth only displays its own settings panel.
- Expanded FM Synth to two serial modulators and a carrier, with per-operator wave sculpt, selectable carrier feedback, and an output filter.
- Matched FM Wave Sculpt headings to Mono Synth and added a fully disableable Modulator 1.

## 2026-07-20 — v5 archived

- Refined sequencer utilities and pattern settings.
- Added grain voice controls and envelope shapes, and unified envelope and window controls.
- Added per-track swing controls.

## 2026-06-19 — v4 published

- Added pitch assignment for selected steps, including scale-aware pitch ranges.
- Added inline pattern effect settings and a prototype of momentary performance effects.

## 2026-06-04 — v0.3 archived

- Continued development of sample voices, playback, sequencing, and effects.

## 2026-05-18 — v0.2 snapshot

- Expanded the prototype's sample, voice, effects, and pattern workflow.

## 2026-04-10 — v0.1 tag

- Early prototype of sample-based granular and chop playback with pattern sequencing.

## 2026-03-25 — Project started

- Established the browser prototype with sample loading, waveform and region editing, granular and chop playback, and BPM-synced sequencing.

## Changes after v5 was archived

- **2026-07-22:** Fixed track pan centering.
- **2026-07-23:** Refined the sequencer utility strip and added pitch-key click feedback.
- **2026-08-01:** Improved the first-run default session.
- **2026-10-27:** Added scheduled, discrete pattern delay repeats.
